# 🎵 Sistema Musical

Projeto desenvolvido por **Thiago Marcelino Vieira** como parte da disciplina de **Linguagem de Marcação** do curso técnico em **Desenvolvimento de Sistemas** no **SENAI 118**.

O **Sistema Musical** é uma interface web front-end completa desenvolvida para o gerenciamento e catalogação de artistas, álbuns e músicas, contando com fluxo de login, cadastro, filtros e biblioteca musical.

---

## 📌 Funcionalidades

- **Tela de Login (`login.html`):** Autenticação simples com campos de usuário e senha.
- **Painel Principal / Menu (`index.html`):** Navegação centralizada para os módulos da aplicação.
- **Gerenciamento de Artistas (`cadastro_artista.html`):** Formulário de cadastro de artistas (nome, gênero, país, foto) e tabela de visualização.
- **Cadastro de Músicas (`cadastro_musica.html`):** Vínculo de faixas a artistas, inclusão de capa, letra e link direto para o YouTube.
- **Biblioteca Musical (`listagem_musicas.html`):** Exibição das faixas cadastradas com barra de busca e filtros por artista/gênero.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de formulários, tabelas e menus.
- **CSS3:** Estilização customizada com uso de variáveis (`:root`), Grid Layout, Flexbox e responsividade via *media queries*.

## 📂 Estrutura de Arquivos

```text
sistema-musical/
```

## 🚀 Como Executar o Projeto

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/ThiagoMarcelinoVieira/sistema-musical.git
   ```

2. **Navegue até o diretório:**
   ```bash
   cd sistema-musical
   ```

3. **Abra no navegador:**
   - Dê um duplo clique no arquivo `login.html` ou `index.html`.
   - Ou utilize a extensão **Live Server** no VS Code para rodar localmente.
